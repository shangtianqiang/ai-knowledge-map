DeepSeek Harness
是什么？

DeepSeek Harness（命令行里叫 dsh）是 DeepSeek 开源的 Agent 运行框架：它包在模型外面，提供工具、会话、沙盒和插件系统——让模型不只是回答问题，而是能动手干活。

比如，对它说一句"每周五下午整理项目记录、生成周报"，它到点自动跑完，成果以文档、表格、PDF 直接预览。官方给它的定位只有一句话：Everything is a Plugin，一切皆插件。

PLUGIN 1 · 换脑子

模型适配器

PLUGIN 2 · 给手脚

工具与审批

文件系统、终端、子进程、后台任务都是可插拔组件；执行要过 pre-execute → execute → post-execute 把关流水线。

PLUGIN 3 · 连循环

Agent 循环与会话

连 Agent 循环本身都是插件。会话日志是唯一事实源——session.jsonl，每次模型请求都能从日志完整重建。

为什么值得看

没有特权内核，
每个部件都能被换掉。

官方仓库的副标题就是理念：Everything is a Plugin——模型适配器、工具注册表、会话日志，乃至 Agent 循环本身，都是可插拔的组件。扩展方式只是"把插件挂到其他插件旁边"，卸载时注册项自动撤销。甚至有一篇论文为这套范式背书：《A Programming Paradigm for Spatiotemporal Composability》。

01

一切皆插件

由开源插件系统 Cordis 驱动：服务、类型化事件、可逆副作用。替换提供方即替换产品形态——比如把文件系统与进程指向远程沙盒。

02

日志是唯一事实源

会话是只追加的事件日志（JSONL + zstd 压缩）："每个模型请求都必须能从日志重建"。取消是安全的，历史不会被悄悄改写。

03

生产级的配件

审批策略、沙盒、凭据、遥测都在第一层 dsh-base 里，可用 patch 整体替换；执行轨迹、工具调用详情、计时信息随时可查。

安全与可靠性设计在哪里

  • 审批策略——工具执行前可被策略拦下，"自动授权审查"插件（实验性）帮你审 Agent 的每个动作。
  • 沙盒——启动进程前由沙盒包装 argv，写入被限制在沙盒根目录内；沙盒提供方可整体替换（如远程沙盒）。
  • 把关流水线——每个工具调用都经过 pre-execute → execute → post-execute，任一环节可拦截。
  • 日志不可变——会话事件只追加、已提交路径不重命名不删除；取消请求不会污染历史。
  • 可观测——开发者工具可查看执行轨迹、工具调用详情与计时信息，排查问题不用猜。
  • 凭据独立——设置与凭据是独立插件，不散落在配置文件里。

官方的诚实提醒：项目处于开发者预览阶段，"未来将出现破坏兼容性的变更"。给 Agent 的权限、接的模型、装的插件都值得审慎——生产环境建议隔离评估后再上。

常见问题

"Harness"这个词到底是什么意思？+
直译是"挽具"——套在马身上让人能驾驭马的那套装备。工程语境里指包在模型外面的运行时骨架：模型负责生成"下一步做什么"，harness 负责给模型工具、记住上下文、真正执行动作、并保证安全。模型是马，Harness 是那套挽具。
它和网页版 DeepSeek / ChatGPT 有什么区别？+
网页聊天只能"说"；Harness 让模型"做"：读写文件、跑终端、后台批处理、定时任务，成果以 docx、xlsx、HTML、PDF 直接预览。而且整套东西运行在你自己的机器上，过程有日志、有轨迹、可审计。
免费吗？开源吗？+
工具本身 MIT 开源、完全免费，运行 Harness 不花钱。模型调用按你接入的提供方计费——用 DeepSeek API 就按其 API 价格，换成别家就按别家的价格。
只能配 DeepSeek 的模型吗？+
不是。模型适配器本身就是插件，官方支持接入其他提供方的模型——这正是"一切皆插件"的直接好处：换模型不动主体，改配置就行。
和 Claude Code 这类工具有什么区别？+
定位相似（都是让模型动手干活），但路线不同：Harness 把整个骨架——循环、工具、审批、存储——都做成可替换插件，并提供 Web / 桌面 / SDK / headless / ACP 多种形态，还面向普通用户做了界面。有第三方评测把它与 Claude Code 对比，称其为少数"从第一性原理出发"系统化设计的开源 Agent 框架。
现在上生产靠谱吗？怎么扩展？+
官方定位是开发者预览，明确警告会有破坏性变更——生产环境建议隔离评估。扩展方面：可安装现成插件（GitHub topic dsh-plugin）或自制插件，甚至能对话式创建——官方演示里 5 分 24 秒就做出了一个"番茄时钟"悬浮插件。
