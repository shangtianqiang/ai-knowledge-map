学习路径

八站，一条主线

顺序不是随意的：先懂模型怎么"想"、你怎么"问"，再看它会怎么"错"、知识怎么"补"，最后是"动手"的能力与真实的产品。点击任意卡片进入专题页。

01怎么想

思维链

让模型把中间步骤写出来再作答——2022 年的一篇论文，如今长成了"推理模型"整个品类。

开始阅读 ≈ 6 min 02怎么问

Prompt 工程

提示词不是咒语，是你与模型的接口规范：说清楚、给示例、定格式、配评测。

开始阅读 ≈ 7 min 03怎么错

幻觉

流畅、自信、错误。它不是撒谎，是机制的伴生物——三个诱因、四道闸门，只能管理不能根除。

开始阅读 ≈ 6 min 04怎么补知识

RAG

让模型开卷考试：先从你的资料里检索，再作答——答案有出处、可更新、可授权。

开始阅读 ≈ 6 min 05怎么连接

MCP

AI 应用的 USB-C：一个开放协议，让工具与数据即插即用——连竞争对手都愿意共建。

开始阅读 ≈ 6 min 06怎么动手

Agent Harness

包在模型外面的运行时骨架：循环、工具、沙盒与留痕。模型负责聪明，它负责可靠。

开始阅读 ≈ 7 min 07开源样本

DeepSeek Harness

"Everything is a Plugin"：DeepSeek 开源的 Agent 运行框架，GitHub 26 万 Star 的当代实现。

开始阅读 ≈ 7 min 08真实产品

飞书 CLI

给 Agent 装上飞书的那双手：官方开源的命令行工具，一行命令读消息、写文档、查日历。

开始阅读 ≈ 6 min

术语速查

40+ 个词，看懂 AI 新闻

读公众号、看发布会时最常见的那些词，按主题分组。带下划线的词已有专题页，点击可直接深入。

模型本体8 词+
Token 词元模型读文本的最小单位，一个汉字约 1–2 个 token；计费、限速、上下文上限都按它算。
上下文窗口模型一次能"看到"的内容上限（如 128K、1M token），超了就要靠压缩或检索。
预训练 / 微调先"读遍互联网"打基础（Pre-training），再用专业数据调教出特定能力（Fine-tuning / SFT）。
RLHF人类反馈强化学习：让人给回答打分，模型据此"学乖"——ChatGPT 好好说话的关键一步。
MoE 混合专家大模型内部分成很多"专家"，每次只唤醒几个——DeepSeek V3 的标志性设计。
蒸馏让小模型模仿大模型的输出来变强，"以师徒制降本"。
量化把模型参数从高精度压成低精度，换更小内存与更快速度，牺牲一点智商。
多模态能同时处理文字、图片、音频、视频的模型。
模型行为6 词+
幻觉流畅、自信，但错误或无依据的输出。有专页 ↗
温度 Temperature随机性旋钮：调低稳定保守，调高有创意也易跑偏。
对齐 Alignment让模型行为符合人类意图与价值观的总称。
越狱 Jailbreak绕过安全限制，骗模型输出违禁内容的攻击手法。
提示注入把恶意指令藏进网页、文档里等 AI 去读——Agent 时代最著名的安全威胁。
拒答 Refusal安全边界触发后，模型回复"我不能帮你做这个"。
知识接入5 词+
RAG检索增强生成：先搜资料再作答，答案有出处。有专页 ↗
Embedding 嵌入把文字变成向量，意思越近的文本向量越接近。
向量数据库存向量、按"意思"搜索的数据库（FAISS、pgvector、Milvus 等）。
重排 Rerank初筛之后用小模型精细排序，提升检索质量。
长上下文 vs RAG整本塞进窗口 vs 只检索相关几页——实践中常混用。
Agent 与工具7 词+
Agent能感知、规划并动手执行任务的 AI 系统。有专页 ↗
Harness / Scaffolding包在模型外面的运行时骨架 / 开跑前组装的静态件。有专页 ↗
Agent 循环取观察 → 出动作 → 回填，直到模型说"做完了"。
Function Calling模型输出结构化的"调用请求"，由外部程序执行。
MCPAnthropic 开源的连接标准，"AI 的 USB-C"。有专页 ↗
子智能体主 Agent 派出去干专项任务的分身，各带独立上下文。
Human-in-the-loop关键动作先弹审批等人拍板——自治程度的反面刻度。
推理与评测8 词+
思维链 CoT把中间步骤写出来再作答，最著名的提示技法。有专页 ↗
推理模型回答前先内部"打草稿"的模型（o 系列、DeepSeek-R1）。有专页 ↗
测试时算力推理阶段多花算力换质量——"想得更久"也算变强。有专页 ↗
ReAct推理与行动交替的循环，Agent 的思想模板。有专页 ↗
Benchmark 基准标准化考卷：MMLU（知识）、SWE-bench（修 bug）等。
Eval 评测工程自己出卷子持续测模型与提示词的效果——好提示是测出来的。
LLM-as-a-judge用一个模型给另一个模型的输出打分，规模化自动评审。
红队测试专职攻击自家模型找漏洞的安全实践。
产品与运行5 词+
系统提示词产品出厂自带、常驻生效的隐形指令——产品的"性格"。有专页 ↗
上下文工程提示词工程的升级版：管理模型看到的全部上下文。有专页 ↗
流式输出一个字一个字往外蹦的输出方式，体验更快。
模型路由简单问题给小模型、难题给大模型——省钱又保速度。
速率限制API 每分钟允许的调用量，TPM / RPM 缩写的来源。
