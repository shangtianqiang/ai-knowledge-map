给想让 AI 记住你的人的实用指南

记忆
是什么？

记忆（Memory）是让 AI 跨会话记住事实与偏好的机制：短期记忆就是上下文窗口——关掉就忘；长期记忆靠外部存储——把重要的事存下来、下次对话取回来。一句话：窗口是工作台，记忆是抽屉。

比如第二次聊天时它还记得你是素食者、项目用 React、报告要周报体——不用每次自我介绍。这些"关于你的事实"存在模型之外的抽屉里，每次对话开始时再取回工作台。

为什么重要

没有记忆的 AI，
每一次对话都是初次见面。

记忆本质是个检索问题——与 RAG 同源：RAG 检索的是"文档知识"，记忆检索的是"关于你的事实"。真正难的不是存——向量库、文件、数据库都是现成的；难的是决定写什么、何时更新、如何遗忘——以及用户对"它知道我什么"的掌控感。

01

记忆是检索问题

同一套"存-找-注入"的技术栈：RAG 对着文档库，记忆对着用户档案。做过 RAG，记忆就懂了一半。

02

写什么比存什么难

存储是现成商品；写入决策才是难题：什么值得记、记多久、和旧记忆怎么合并、错了怎么撤。

03

遗忘与隐私是一等公民

过期、纠错、一键删除不是"以后再加"的功能。没有掌控感的记忆系统，用户不敢用、企业不敢上。

记忆机制的编年史

  • 2023 向量库当记忆

    RAG 兴起，同一套"嵌入 + 检索"顺手被用来存关于用户的信息——记忆与 RAG 从此同源，各家手工拼装。

  • 2024 · 2 ChatGPT Memory 产品化

    OpenAI 上线跨对话记忆：自动记、可查看、可删除——"记得你的 AI"第一次到达亿级用户。

  • 2025 memory tool + mem0 论文

    Anthropic 推出 memory tool（/memories 文件目录）；mem0 发论文（arXiv:2504.19413）并成为最热的开源记忆层——记忆进入工具化。

  • 2026 记忆标准化

    MCP memory server 等可插拔组件普及；跨应用、跨 Agent 的"随身记忆"被广泛讨论。

设计张力与常见误解

  • 记多 vs 记准——噪声记忆污染回答：错记一条偏见，之后每一次回答都带着它。
  • 自动 vs 授权——自动记忆体验顺滑，隐私法规与用户掌控却要求知情、可拒、可删。
  • 共享 vs 隔离——工作记忆与私人记忆要不要分开？混在同一个抽屉里就是事故素材。
  • 成本——每轮检索都花 token：记忆越多，回答越贵、越慢，要算经济账。
  • 新鲜 vs 稳定——事实会变：住所、工作、偏好都不是常量，记忆要不要跟着变、怎么变。
  • 透明 vs 黑箱——能查看它记了什么，是信任的底线；黑箱记忆没人敢长期用。

三个常见误解：① "模型自己会记住"——窗口关了就忘，长期记忆全是外挂工程，不是模型天赋；② "记得越多越好"——错记一条偏见，次次回答都歪：噪声记忆是污染源；③ "记忆 = 历史聊天记录"——那是原始日志，记忆是从日志里提炼出来的事实档案。

常见问题

记忆和 RAG 是一回事吗？+
技术同源，对象不同：都走"存储-检索-注入"，但 RAG 检索的是文档知识（外部世界），记忆检索的是关于你的事实（用户状态）。工程上常共用一套向量库设施，但写入策略完全不同：RAG 的库由你喂进去，记忆的库从对话里自己长出来。前半套技术见姊妹篇《什么是 RAG？》。
它会记错吗？怎么纠正？+
会。自动抽取会误解、会过时、会把一次玩笑当事实。纠正路径：直接说"你记错了，应该是……"，多数系统会据此更新记忆；ChatGPT 可在设置里逐条编辑或删除。更稳的做法是把"用户纠正"当作最高优先级的写入信号。
怎么删除它记的东西？+
消费级产品都有一键入口：ChatGPT 设置 → 个性化 → 记忆，可逐条删、全部清除，也能整体关闭功能。开发侧（memory tool、mem0）因为存储在你自己手里，删除就是删文件、删记录——这也是自建记忆在合规上的天然优势。
多人、多设备怎么同步？+
关键是把记忆放在服务端而不是端上：按用户 ID 隔离的向量库或数据库，任何设备登录都读同一份。要小心的是隔离边界——用户之间绝不能串；同一用户的工作与私人上下文，也建议分 namespace 存。
企业落地要注意什么？+
四件事：授权（记什么要让用户知情同意）、隔离（租户 / 用户 / 场景三层隔离）、可审计（谁写的、何时写的、改过什么要有日志）、可删除（法规级的删除权）。企业场景里，"可控"的优先级高于"聪明"。
本地能玩吗？+
能，而且门槛很低：MCP memory server（npx @modelcontextprotocol/server-memory）给本地 Agent 配知识图谱记忆；mem0 开源可自托管；Claude Code 的 CLAUDE.md 则是最朴素的"文件记忆"。想试什么口味都跑得起来。
