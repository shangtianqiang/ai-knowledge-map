AI 工具
怎么选？

现在的问题不是没有 AI 工具，而是太多了：编码 Agent、通用助手、自主任务、开发平台四大品类，国内外双生态。这一页给你一张经核实的产品地图和一套选型方法——先场景、后约束、再试跑。

同样是"让 AI 干活"：写代码要编码 Agent（Claude Code、Codex CLI），日常问答用通用助手（DeepSeek、Kimi、ChatGPT），搭自动化用平台（扣子、Dify）。选错品类，再强的工具也不顺手；选对品类，前几名都够用。

为什么这样选

没有最好的工具，
只有匹配场景的工具。

排行榜测的是通用基准，你的任务长在具体场景里：写代码的人在意终端与仓库，做运营的人在意发布渠道，管数据的人第一问是合规。工具是放大器——工作流不行，换十个工具也白搭。协议化时代（MCP、Skill）还有个新原则：优先选可迁移的，别把自己锁死在单品里。

01

场景优先

先定品类再挑产品：编码、问答、自主任务、自建平台四选一，错品类无解，对品类内前几名都够用。

02

组合优于单品

MCP 让工具可拼装、Skill 让手艺可携带——常见配置是"通用助手日常用 + 编码 Agent 干活 + 平台搭自动化"。

03

保持可迁移

把提示词、技能、MCP 配置这些"资产"放在工具外——换工具时资产带走，迁移成本趋近于零。

一段工具编年史

  • 2021–2022 辅助时代

    GitHub Copilot 让"AI 补全"进入日常；ChatGPT 上线，通用助手品类从此被定义。

  • 2024 自主任务登场

    Devin 打出"AI 软件工程师"概念，Computer Use 让 AI 直接操作电脑——"给目标不给步骤"成为新品类。

  • 2025 · 上半年 编码 Agent 元年

    Claude Code（2 月）之后，Codex CLI、Gemini CLI、Qwen Code 相继开源发布；Manus 出圈引爆通用 Agent 讨论；各家上线深度研究。

  • 2025 · 下半年 平台与协议成熟

    扣子、Dify、百炼等平台普及低代码搭建；MCP 被各大厂采纳，工具生态开始可组合。

  • 2026 品类细分与趋同

    各品类头部趋同，差异转向工作流与生态；选型从"哪家最强"变成"哪套组合适合我"。

选型张力与常见误解

  • 国际 vs 国内——能力在收敛；决策变量是数据合规、网络环境与中文场景适配。
  • 闭源订阅 vs 开源自建——订阅省心上限高；自建可控可审计，但要养人和算力。
  • 通用 vs 垂直——通用助手什么都行，垂直工具在窄场景更深；先通用补齐，再按痛点上垂直。
  • 订阅包月 vs 按量付费——重度用户包月划算，轻度用户按量灵活；先按量试，再决定包月。
  • 一站式平台 vs 命令行组合——平台给非程序员生产力，CLI 给开发者自由；别用错人群。
  • 尝鲜 vs 稳定——生产环境求稳，个人环境尽可尝鲜；用"资产外置"降低尝鲜成本。

三个常见误解：① "榜单第一 = 最适合我"——榜单测通用基准，你的场景才是考场；② "工具决定上限"——工具是放大器，工作流和方法才是杠杆（本系列前 11 课都是方法）；③ "选定就用一辈子"——格局月月变，季度重审 + 资产可迁移才是正解。

常见问题

零基础该从哪个开始？+
从通用助手开始（国内 DeepSeek、Kimi、豆包，国际 ChatGPT、Gemini）：免安装、免费额度够用、立刻见效。用满一个月，你会自然知道自己需要什么——那时候再看编码 Agent 还是平台。
编码 Agent 选哪个？+
没有唯一答案，社区常见做法是同题试跑：拿同一个真实任务分别跑 Claude Code、Codex CLI、Gemini CLI（前两家开源可自托管，Gemini CLI 有免费额度；国内团队可加试 Qwen Code）。跑一周，看你最在意的是质量、速度还是价格。别信榜单，信自己的仓库。
企业数据敏感，怎么办？+
三条路按敏感度递进：选国内合规产品；开源自建（Dify + 开放权重模型，数据不出内网）；编码场景用本地 CLI + 私有化模型。原则只有一条：数据分级，敏感数据不进公网服务。
免费额度够用吗？+
轻度使用基本够：通用助手各家都有免费层，Gemini CLI 这类也提供每日免费请求额度。重度使用（每天大量编码、批量任务）迟早要付费——先免费用出依赖，再为真实工作流付费，顺序别反。
要不要自己搭一套？+
看需求：只是想用，别自建——成熟产品迭代比你快；有定制、合规、成本三重需求再自建（Dify 起步最稳）。自建的真实成本不在搭建在维护：模型升级、权限、评测都要人管。
多久重新评估一次工具？+
季度重审足够：每季度用同一组真实任务把在用工具和两个候选各跑一遍，按结果决定去留。配合"资产外置"（提示词、技能、MCP 配置放在工具外），迁移成本很低，随时能换。
