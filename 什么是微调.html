微调
是什么？

微调（Fine-tuning）是在预训练模型上用你自己的数据继续训练，改变它的行为、风格与领域能力——一句话定位：记事实用 RAG，学风格与技能才微调。

比如客服模型通过微调学会你们的话术与口径，回答格式固定、口吻统一——这是提示词和 RAG 都做不到的"肌肉记忆"：规范长进了权重里，不用每次重复交代。

为什么重要

微调改的是行为，
不是知识库。

这是厂商文档反复强调的共识：要事实、要出处、要随时更新——用 RAG，知识放外部检索，可溯源、可替换；要口吻、要格式、要稳定复现的行为——用微调，规范长进权重里。微调失败最常见的原因不是训不好，而是用错了工具：想让模型"记住"文档库的人选择了微调，结果知识没存住，风格也没改好。

01

数据质量 > 数量

几百条口径统一的高质量样本，常胜过几千条原始聊天记录。清洗、去噪、对齐格式与禁忌——数据工程占了微调项目的大头时间。

02

行为可学，事实难存

微调擅长固化"怎么做"：口吻、格式、流程。硬塞"是什么"的知识既不可靠也难更新，还会随时间悄悄过期——那是 RAG 的地盘。

03

评测护航

微调完可能忘掉通用能力（灾难性遗忘）。领域测试集之外必须跑通用回归集——专才上线前，先确认通才没有掉线。

微调的编年史

  • 2019 BERT 微调时代

    "预训练 + 微调"成为 NLP 标配范式：下游任务接上分类头，用领域数据把 BERT 调成专用模型——微调这个词由此进入大众视野。

  • 2021 LoRA 论文

    微软发布低秩适配（arXiv:2106.09685）：冻结预训练权重、只训练注入的低秩矩阵，可训练参数骤减——大模型微调的成本降了一个数量级。

  • 2022 InstructGPT

    OpenAI 发表 SFT + 奖励模型 + RLHF 三段式（arXiv:2203.02155），"指令微调 + 人类反馈"成为对齐主线，也是 ChatGPT 的前身。

  • 2023 API 与开放权重

    GPT-3.5 微调 API 上线，闭源模型也能定制；Llama 开放权重发布，开源社区掀起 LoRA 微调热潮。

  • 2024+ LoRA 生态平民化

    QLoRA、PEFT 等工具成熟，消费级显卡可微调十亿级参数模型；微调从研究课题变成工程师的常规手段。

  • 2026 企业知识资产化

    企业把话术、口径、领域行为沉淀为数据集与 LoRA 权重，与 RAG 组合部署——"定制能力"本身成为可复用的知识资产。

设计张力与常见误解

  • RAG vs 微调——事实与出处选 RAG，风格与行为选微调；生产系统常常两者叠加，各管一段。
  • 全参 vs LoRA——全参上限高但贵且难保存；LoRA 便宜、可插拔，多数场景从 LoRA 起步验证。
  • 灾难性遗忘——专才变强可能以通才退步为代价；混入通用数据、控制轮数、跑回归评测来对冲。
  • 数据合规与版权——数据一旦训进权重就难撤回：隐私、版权、商业机密必须在入口把关。
  • 成本与周期——显卡、数据清洗、评测、重训运维都是持续成本；一次微调不等于一劳永逸。
  • 通用 vs 专用——越专用越偏离通才；多任务并存时，专用与通用模型分工比"一个全能"更稳。

三个常见误解：① "微调能记住我的文档库"——不能，知识注入用 RAG，微调学的是行为与风格；② "微调后模型全面变强"——它只是在特定维度变好，可能牺牲通用性；③ "LoRA 便宜所以随便调"——真正的大头是数据准备与评测，训练只是中间一步。

常见问题

微调和 RAG 怎么选？+
分工看目标：要事实、要出处、要随时更新，选 RAG——知识放外部，可溯源可替换；要口吻、要格式、要稳定复现的行为，选微调。OpenAI 官方文档也是这个口径：注入知识靠检索，微调负责行为。两者不互斥：RAG 兜住事实、微调统一风格，是生产系统的常见组合。
需要多少数据？+
经验值：数百到数千条高质量样本通常足以改变行为。OpenAI 官方称最少 10 条就能起一个任务、50–100 条已能看到改善；复杂任务或开源模型可能需要更多。关键不在量：几百条口径统一的好样本，常胜过几千条原始聊天记录。
大概多少钱？+
两条路线两种账：闭源 API 按训练时长 + 调用计费，还有托管版模型的调用溢价；开源 + LoRA 的主要成本是显卡与你的时间。价格随厂商与机型变动很快，本站不报具体数字——动手前以官方价格页为准，并记得把数据清洗与评测的人力算进去。
会让模型变笨吗？+
可能会，这叫灾难性遗忘：在领域数据上训得太狠，通用能力（常识、推理、指令遵循）可能退步。对冲方法：训练数据里混入通用样本、控制训练轮数、微调完必跑通用回归评测——专才变强的前提是通才不掉线。
多久做一次？+
不是一劳永逸：话术口径变了、底座模型升级了、评测发现漂移了，都要重训或增量微调。把数据集 + 评测集 + 训练脚本当代码管理，重训才便宜。也正因如此，能用提示词解决的别急着微调——先提示，后 RAG，最后才是微调。
个人能玩吗？+
能，这正是 LoRA 时代的变化：开放权重 + PEFT 等工具，一张消费级显卡（或租来的算力）就能微调十亿级参数的模型练手，社区有大量教程与公开数据集。但先记住边界：它学的是行为，不是外挂硬盘——想给它加知识，请看姊妹篇 RAG。
