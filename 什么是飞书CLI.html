飞书 CLI
是什么？

飞书 CLI（命令行里的 lark-cli）是飞书官方开源的终端客户端：一行命令读消息、写文档、查日历、建多维表格——它也是 AI Agent 操作飞书的那双手。

比如，在终端输入一条命令，把会议纪要直接写成一篇飞书文档；或者对 Claude Code 说一句"把本周评审意见整理成周报，发到项目大群"，它通过 CLI 在飞书里把事办完——你只管看结果。

把重复劳动交给命令

三个最常见的自动化场景。它们是社区里的典型玩法，具体效果取决于你的权限范围与配置。

消息摘要定时

群消息 → 每日简报

为什么是命令行

以前是你操作飞书，
现在是 AI 操作飞书，你只管拍板。

官方文档的比喻很直白：AI Agent 看不到你的日历，读不了你的群聊，打不开你的文档——飞书 CLI 就是给 Agent 的那双手。它把两百多个飞书操作封装成稳定的文本接口：输入是命令，输出是结构化 JSON，任何能开终端的 AI 都能用。

01

为 Agent 而生

26 个官方 Agent Skills 开箱即用，Claude Code、Cursor、Codex、TRAE 装上就能用；命令本身做过"AI 友好"实测调优。

02

机器可判断

JSON 输出契约：成功与否看 ok == true，错误信封走 stderr，Agent 不用猜测界面截图里发生了什么。

03

先看再执行

--dry-run 预览、schema 自省、分页与限速参数，把危险操作挡在真正发生之前。

你需要提供什么

STEP 1 · 10 秒

装上它

一条 npm 命令，装完自动配好补全。需要 Node.js 18+ 环境；没有 Node 也可以克隆 Go 源码构建。

❯npx @larksuite/cli@latest install
STEP 2 · 约 5 分钟

配一次，用很久

首次使用初始化配置并授权。凭证会被放进操作系统原生密钥链，之后所有命令直接可用。

❯lark-cli config init
❯lark-cli auth login --recommend

不想授权个人数据？也可以直接用：仍能发消息、建文档，只是读不了你的日历和私信；等 AI 真需要时会自动发起授权提示，你在手机上点一下确认即可。应用与权限始终遵循企业开放平台的统一管控规则。

安全边界在哪里

  • 凭证不落明文——App Secret 与令牌保存在 macOS Keychain / 凭据管理器等系统密钥链里。
  • 令牌默认 DPoP 绑定——即使 token 泄露也难以被冒用，可用 config set dpop 调整级别。
  • 输入防注入、输出净化——终端内容经过清洗，降低提示词注入被带进 Agent 上下文的风险。
  • 最小授权——按业务域授权（如 auth login --domain docs），用不到的权限不开。
  • 企业管控不打折——CLI 只是一键创建应用，权限审批、审计仍走企业开放平台的原有流程。
  • 可预览可撤销——--dry-run 先看后跑，auth logout 随时下线本机登录态。

官方的诚实提醒：工具本身做了不少防护，但模型幻觉与提示词注入的风险仍然存在。官方建议把对接的机器人当作私人助手使用，不要拉进群聊；给 AI 的权限够用就好。

常见问题

飞书 CLI 免费吗？+
工具本身 MIT 开源、完全免费。使用需要一个飞书"企业自建应用"，在开放平台创建应用不收费，lark-cli config init 还能一键帮你创建。API 调用消耗的是应用自身的频率配额，个人与中小团队场景完全够用。
需要企业管理员审批吗？+
取决于企业设置：创建应用通常人人可以，但开通敏感权限（读私聊、通讯录等）时，部分企业会要求管理员审核。权限不足时 CLI 会在报错里直接给出 console_url，按提示去开发者后台补开即可。
它和飞书机器人是什么关系？+
机器人是飞书里"会说话的应用"，CLI 是操作飞书的"手柄"，两者常常配合：机器人收指令，CLI 办事情。CLI 支持两种身份——--as user 以你本人的身份读写你的日历和文档，--as bot 以应用身份收发消息、操作应用自己的资源。
它和 MCP 是什么关系？+
MCP 是让 AI 接工具的通用协议，飞书 CLI 则是官方做好的"现成实现"：鉴权、schema 自省、JSON 输出契约、Agent Skills 都已内置。官方在 OpenClaw 等平台上的飞书插件，底层也是基于这套 CLI 构建的。对个人用户来说，装上 CLI 基本等于跳过自建 MCP 服务的那一整套调试。
我的账号安全吗？+
CLI 在本机运行：凭证进系统密钥链、令牌默认 DPoP 绑定、不经过第三方服务器。风险主要来自把过大的权限交给 AI——官方明确提醒警惕模型幻觉与提示词注入。建议按业务域最小授权、先 --dry-run 再执行，并优先作为私人助手使用。
支持 Windows 和国际版 Lark 吗？+
支持。macOS / Windows / Linux 都有官方二进制，通过 npm 一行安装；中文飞书与国际版 Lark 都能登录使用。工具迭代很勤，截至本页整理时 npm 上已发布 100+ 个版本。
