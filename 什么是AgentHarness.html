Agent Harness
是什么？

Agent Harness 是包在大模型外面的运行时骨架：调用模型、路由工具调用、编排上下文、决定何时停止、用沙盒和审批兜住安全——模型负责思考下一步，Harness 负责让这一步真实发生。

社区常用一个公式：Agent = Model + Harness。同一颗模型，套上 Claude Code 是终端里的程序员，套上 DeepSeek Harness 是能定时整理文档的助手——模型没变，变的是挽具。业内还有句玩笑话："If you're not the model, you're the harness."

为什么重要

同一个模型，
换一套 Harness，就是另一个 Agent。

Hugging Face 术语指南的总结很锋利："The harness is what makes the agent run."（让 Agent 跑起来的，是 Harness。）社区流传的观察更直白：有团队只换 harness 不换模型，评测名次从三十名开外冲进前五；同一颗模型在不同 harness 里跑分能差出一截——第三方整理，本站未复测，但方向上可信。

01

看什么，它说了算

上下文窗口里装什么、何时压缩、注入哪些工具结果——模型的"视野"由 harness 编排，context engineering 的主战场就在这里。

02

做什么，它来执行

模型只产出结构化的"意图"（tool call）；读写文件、跑终端、调 API，全部由 harness 在沙盒里落地、回填、留痕。

03

何时停，它来兜底

停止条件、错误重试、步数预算、危险动作审批——Agent 的纪律性不是模型的美德，是 harness 的机制。

一个词的四次出场

  • 2021 评测时代

    EleutherAI 发布 lm-evaluation-harness：评测脚本从此有了统一的名字，"harness" 进入大模型工程词汇表。

  • 2024 接口觉醒

    SWE-agent 论文提出 Agent-Computer Interface（ACI）：为模型设计工具接口，正式成为研究方向——harness 的学术前身。

  • 2025 产品时代

    Claude Code、Codex CLI 相继发布，"循环 + 工具 + 沙盒"被做成千万用户手里的产品，Agent = Model + Harness 成为共识公式。

  • 2026 显学时代

    OpenAI 发文 harness engineering，DeepSeek 开源"一切皆插件"的 harness，Hugging Face 撰文为术语正名——骨架本身成了研究对象。

设计取舍：三对张力，两处误解

  • 自由度 vs 安全——工具给得越强，沙盒与审批就要越硬；能力与纪律必须一起涨。
  • 越全 vs 越贵——上下文塞得越满通常越聪明，也越慢越贵；压缩与取舍是每天的功课。
  • 通用 vs 专用——编码 harness 与办公 harness 的工具集、默认值完全不同，没有万能骨架。
  • 强绑定 vs 可插拔——Claude Code 与模型深度耦合，dsh 把适配器做成插件；两条路线各有拥趸。
  • 静态 vs 运行时——scaffolding 开跑前组装好，harness 在每一轮现场决策；混着叫会吃亏，尤其在训练管线里。
  • 评测 vs 实战——同一个 harness，跑分好看不代表干活好用；设计目标本就不同。

两个常见误解：① Harness 不是模型的一部分——它跑在你的机器上，属于工程层，换模型不换它也能活；② Harness ≠ Harness.io——那是一家同名的 DevOps 平台公司，纯属重名。另外，社区术语尚未完全统一，读文章时留意语境。

常见问题

Harness 和 LangChain 这类"框架"是一回事吗？+
有重叠，侧重不同。框架给你一堆积木自己搭；harness 强调开箱即用的运行时骨架——循环、工具执行、安全、界面都配好，更像"产品化的框架"。dsh、Claude Code 这类 harness，可以理解成把框架的活儿替你干完了。
为什么 2026 年突然人人都在说 harness？+
模型能力趋同之后，体验差异越来越多来自模型之外：上下文怎么编排、工具怎么给、动作怎么管。评测、安全、训练也都依赖这层骨架——它同时是各家的"护城河"和行业共同语言，自然被反复谈论。
Harness 和 MCP 是什么关系？+
分工不同：harness 是运行时骨架，MCP 是给骨架接外部工具的协议。harness 消费 MCP server，把文件、搜索、企业系统等能力挂进工具层——骨架与插头的关系。
评测 harness 和 Agent harness 是同一个词吗？+
同源、不同物。评测 harness 管"怎么考"：固定场景、记录指标；Agent harness 管"怎么干活"：真实环境、动态循环。今天口语里的 harness 多指后者，但读评测文章时多半是前者——看语境。
我自己能搭一个吗？+
能，核心真的不大：一个循环、一次工具执行、一份会话存储，几十行就能跑起来（见页尾）。想认真用，可以选开源 harness（DeepSeek Harness、OpenHands 等）或成熟产品——自建的价值在于完全掌控安全与定制。
Harness 会盖过模型的价值吗？+
不会，是放大器关系：模型决定上限，harness 决定下限与稳定性。更强模型降低做好 harness 的难度，更好的 harness 把模型能力兑现成产出——两者一起涨。
